CS 350 Portfolio Reflection

Selected Artifacts

For this portfolio submission, I selected my Thermostat Final Project and my Morse Code State Machine project. I chose these projects because they best demonstrate the skills I developed throughout the course and show how I progressed from working with individual hardware components to integrating multiple devices into a complete embedded system.

Project Summary and Problem Being Solved

The thermostat project was designed to simulate how a real thermostat monitors temperature and responds to changing conditions. The system used a temperature and humidity sensor, LCD display, buttons, LEDs, and UART communication to allow a user to monitor and control the system. The goal was to create a working embedded system that could read sensor data, process user input, and provide feedback through both hardware and software components.

The Morse code project focused on using a state machine to control LED outputs and transmit messages. The system allowed the user to switch between different messages while the LEDs flashed the corresponding Morse code pattern. This project helped me understand how state machines can be used to organize program logic and manage timing requirements.

What I Did Particularly Well?

One thing I think I did well throughout this course was troubleshooting. Several of the labs required figuring out wiring issues, software problems, or configuration settings that did not always work the first time. When I ran into problems, I usually worked through them step by step until I found the issue. By the end of the course, I felt much more comfortable diagnosing both hardware and software problems.

I also think I did a good job building on each module. Every project seemed to add another piece to the overall system, and I was able to carry what I learned from one assignment into the next.

Where Could I Improve?

If I were to do these projects again, I would spend more time planning before I started coding. There were times when I jumped into implementation and later realized I needed to reorganize parts of the program. Better planning would probably have reduced some of the debugging and rework that happened later.

I would also like to continue learning more about wireless communication and cloud connectivity because those are common features in modern embedded systems.

What Tools and Resources Am I Adding to My Support Network?

Throughout this course I relied heavily on the Raspberry Pi documentation, Python documentation, lab guides, and hardware reference materials. I also learned the value of reviewing wiring diagrams carefully and using troubleshooting tools such as terminal output and hardware testing commands to isolate problems.

These are resources that I will continue to use in future courses and projects involving hardware and software integration.

What Skills Will Transfer to Other Projects?

The biggest skill I developed was learning how hardware and software work together. Before this course, most of my programming experience involved software only. Working with sensors, displays, buttons, communication protocols, and GPIO interfaces helped me understand how software interacts with physical devices.

Other transferable skills include Python programming, debugging, state machine design, UART communication, I2C communication, and problem solving. These skills will be useful in future computer science courses as well as real-world technology projects.

How Did I Make the Project Maintainable, Readable, and Adaptable?

I tried to keep my code organized by using comments, meaningful variable names, and separating functionality into logical sections. Using state machines also helped keep the system organized because each state had a clearly defined purpose and behavior.

As the projects became more complex, I learned that maintainability is important because it makes troubleshooting and future modifications much easier. The structure I used would allow additional sensors, displays, or features to be added without completely redesigning the project.

Conclusion

This course gave me hands-on experience with embedded systems and helped me better understand how software interacts with hardware. The thermostat and Morse code projects demonstrate the knowledge and skills I gained throughout the course. Looking back at where I started in Module One and comparing it to the final project, I can see a significant improvement in both my technical skills and my confidence working with embedded systems.
